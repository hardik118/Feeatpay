# 🌍 FeatPay – Decentralized CeFi-based Cross-border Transfers

**FeatPay** is a modern, crypto-enabled platform designed to simplify and secure cross-border payments. It combines the efficiency of DeFi with the stability and compliance of CeFi systems.

---

## 🗂️ Project Structure


---

## 🔧 Tech Stack

- **Frontend**: Next.js + Tailwind CSS
- **Backend**: Hono (Cloudflare Workers), Solana SDK
- **Database**: PostgreSQL (Neon)
- **Blockchain**: Solana
- **Payments**: NOWPayments, CoinPayments
- **Shared**: TypeScript types, constants, and utility functions
